# Proyecto demostrativo F1

1. Crear entorno: `python -m venv .venv`
2. Activarlo en Windows: `.venv\Scripts\activate`
3. Instalar: `pip install -r requirements.txt`
4. Iniciar: `jupyter notebook`
5. Abrir `F1/F1_Definición.ipynb` y ejecutar todas las celdas.

**Nota:** Sustituir los datos ficticios por el proyecto real.
