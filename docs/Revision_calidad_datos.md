# Revisión de calidad de datos

## Proyecto
Análisis de matrícula de Institutos Profesionales
de Chile, año 2025.

## Fuente
Consejo Nacional de Educación (CNED).

## Revisión del conjunto de datos
- Registros seleccionados: 4.731.
- Institutos Profesionales: 27.
- Columnas originales: 62.
- Columnas finales: 48.

## Criterios de calidad
- Identificación de valores faltantes.
- Eliminación de columnas sin información útil.
- Tratamiento de datos incompletos.
- Creación de una variable derivada.
- Verificación de dimensiones del conjunto final.

## Resultado
El conjunto procesado queda preparado para
las siguientes etapas del proyecto.
