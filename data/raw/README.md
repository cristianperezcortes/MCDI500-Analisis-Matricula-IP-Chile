# Datos de entrada
Colocar aquí el archivo original `Base-INDICES-Matricula-2005-2026.xlsx`.
El libro (58 MB) no se versiona por tamaño y porque su procedencia necesita
corroborarse. La página oficial conocida del CNED anuncia una versión 2005-2025:
https://cned.cl/institucional/bases-de-datos/
No afirmar equivalencia entre versiones sin cotejar nombre, esquema y SHA-256.

Para CI y reproducción desde un clon limpio sin el libro completo, se incluye el subconjunto sin transformar `data/fixtures/ip_2025_origen_filtrado.csv` (4.731 filas × 62 variables), validado por SHA-256. El libro XLSX original de 260.307 registros fue verificado localmente, pero permanece fuera de GitHub.
